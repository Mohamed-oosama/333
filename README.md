# بوابات المستشفى | MNU 333

يعمل الموقع من `main-platform`. تظهر بوابات المرضى والأطباء والاستقبال وإدارة المستشفى في صفحة البداية. يظهر الأرشيف داخل بوابة المريض من «أرشيفي الطبي»، ويستخدم طبيب الأشعة بوابة الطبيب بحسابه المهني للوصول إلى مساحة الأشعة.

توجّه صفحة الجذر إلى المنصة الرئيسية. روابط الأرشيف القديمة توجّه إلى الأرشيف داخل بوابة المريض. يستخدم الموقع ملفات HTML وCSS وJavaScript مباشرة.

للمعاينة المحلية، شغّل خادم ملفات من مجلد `clarimed-platforms` وافتح المسار `/main-platform/`. مجلد المشروع للنشر هو `clarimed-platforms`، وتبقى ملفات المعاينة على المتصفح المحلي.
