# منظومة MNU 333 الطبية المزدوجة (جاهزة للنشر على Vercel)

يحتوي هذا المجلد المستقل على **موقعين طبيين متكاملين** يعملان بتقنيات الويب النقية (Buildless HTML/CSS/JS) بدون أي تبعيات أو عمليات بناء معقدة:

1. **المنصة السريرية الأساسية (main-platform)**:
   - المستشفى والرعاية المتصلة لمستشفى جامعة المنصورة الجديدة MNU 333.
   - حجز المواعيد وتفادي التعارض للمريض والطبيب.
   - مساحة عمل الطبيب الكاملة وإدارة الزيارات السريرية.
   - استعراض النماذج البحثية السبعة لسرطان الرئة وحالة جاهزية الـ API.
   - مساحة قسم الأشعة، والاستقبال والفرز، وبوابة المريض.
   - تحتوي على زر رابط مباشر للانتقال إلى «منصة الأرشيف الصحي».

2. **منصة الأرشيف الصحي الموحد (rchive-platform)**:
   - الأرشيف الطبي التفاعلي المتكامل للمريض والطبيب.
   - مجموعات الأرشيف الأربع: الزيارات والمواعيد، الفحوصات والنتائج، التقارير والمرفقات، والأدوية.
   - عارض دراسات الأشعة التفاعلي (X-Ray / CT / MRI / PET) بأدوات التكبير، التدوير، شرائح 1-24، والتحكم بالإضاءة والقياس.
   - معرض صور نتائج المختبر مع دعم اختيار ورفع صور حقيقية (JPG / PNG / WebP) محلياً واستعراضها بالحجم الكامل.
   - تحتوي على زر علوي للعودة السريعة إلى «المنصة الرئيسية».

3. **بوابة الدخول الموحدة (index.html)**:
   - صفحة بداية ترحيبية تجمع بين المنصتين وتتيح للمستخدم أو المراجعين اختيار المنصة المطلوبة بضغطة واحدة.

## كيفية الرفع والنشر على Vercel (3 طرق سهلة)

### الطريقة الأولى: الرفع المباشر عبر متصفح الويب (سحب وإفلات)
1. افتح حسابك على موقع [Vercel](https://vercel.com).
2. من لوحة التحكم (Dashboard)، اضغط على **Add New...** ثم **Project**.
3. اسحب مجلد clarimed-platforms بالكامل وأفلته في الصفحة (أو اضغط Import).
4. اضغط زر **Deploy** دون الحاجة لتغيير أي إعدادات؛ فالمشروع لا يحتاج أي أوامر بناء (Framework Preset: Other / No Build Step).
5. خلال ثوانٍ سيصبح الموقع متاحاً على رابط عالمي سريع وآمن HTTPS.

### الطريقة الثانية: الرفع عبر سطر الأوامر (Vercel CLI)
1. افتح Terminal أو PowerShell في هذا المجلد (clarimed-platforms).
2. اكتب الأمر التالي:
   `ash
   npx vercel
   `
3. سيطلب منك تسجيل الدخول وتأكيد نشر المشروع، اضغط Enter للموافقة على الخيارات الافتراضية.
4. للنشر النهائي المباشر (Production):
   `ash
   npx vercel --prod
   `

### الطريقة الثالثة: رفع كل منصة كمشروع منفصل
إذا أردت أن يكون لكل منصة رابط ورأس مشروع مستقل تماماً على Vercel:
- **للمنصة الأساسية**: ارفع مجلد main-platform فقط كمشروع جديد على Vercel.
- **لمنصة الأرشيف**: ارفع مجلد rchive-platform فقط كمشروع جديد آخر على Vercel.
(كل مجلد منهما يحتوي مسبقاً على ملف ercel.json وpackage.json خاص به ومستقل).

## التشغيل والمعاينة المحلية (Local Testing)
يمكنك اختبار المنظومة محلياً في أي وقت بتشغيل أي خادم ويب بسيط، مثل:
`ash
python -m http.server 5183
`
ثم فتح الرابط في المتصفح: [http://127.0.0.1:5183/](http://127.0.0.1:5183/)

## الأمان والتوافق (20 Security Rules)
تم تطبيق الترويسات الأمنية الصارمة في ملف ercel.json:
- X-Content-Type-Options: nosniff
- X-Frame-Options: DENY
- X-XSS-Protection: 1; mode=block
- Referrer-Policy: strict-origin-when-cross-origin
- عزل كامل لبيانات العرض وحفظها محلياً دون إرسال أي بيانات طبية لأي طرف ثالث.
